# Как устроен инструмент

## Поток данных

1. `config.js` связывает физические клавиши с голосами и индексами нот.
2. `app.js` принимает `keydown`/`keyup` и Pointer Events. Сохраняет нажатие по `event.code`, поэтому отпускание Shift раньше основной клавиши не оставляет хор звучать.
3. `AudioEngine.start()` создаёт осцилляторы, огибающую и подключает их к каналу микшера. `InstrumentView.show()` включает клавишу и свечение.
4. `AudioEngine.stop()` планирует затухание по аудиочасам. Событие `onended` освобождает все узлы, включая генератор вибрато. Старый голос не может удалить новый с тем же идентификатором.
5. `Voyage.update()` выдаёт события партитуры с небольшим упреждением. Время берётся из AudioContext, а не из количества отрисованных кадров. После задержки кадра пропущенные ноты отбрасываются, чтобы не возник залп.
6. Один `requestAnimationFrame` обновляет персонажа и следит за сопровождением. При скрытии вкладки анимация отменяется и голоса отпускаются.

## Что изменено при очистке

- Нет промежуточной аудиозаписи, PCM-данных и функций с ошибочными именами «sample».
- Один путь освобождения аудиоузлов вместо отдельных таймеров для каждого тембра.
- Голоса, цвета и клавиши описаны в одном месте.
- CSS собран без старых переопределений и классов удалённых панелей.
- Персонажи используют один PNG-атлас вместо построения SVG из сотен новых элементов на каждом кадре.
- Размер персонажа читается при изменении окна, а не на каждом кадре.
- Исходники и автономный HTML не редактируются независимо: HTML собирается автоматически.
- Предусмотрены отпускание Shift, отмена касания, потеря фокуса, скрытие вкладки и повторные ноты.

## Проверка

`npm test` — детерминированные проверки с моделью Web Audio API; они проверяют логику, но не подменяют браузер и прослушивание. Вручную проверьте флейту, совместные голоса, громкость, касания, мобильный размер, движение персонажа и завершение сопровождения.

Проект не использует внешних библиотек. Требуются браузер с Web Audio API, Pointer Events и ES-модулями; для локальных команд — Node.js 22+.
